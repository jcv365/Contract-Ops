# ADR-001 — Phase 1 Architecture

## Status
Accepted (2026-08-23 — implementation begins per AUDIT-REPORT.md and the approved build plan)

## Decision

Build Phase 1 as a modular, API-first personal Contract Acquisition OS with HUNT, BIDOPS, Recruiter/Company Intelligence, Microsoft Graph Outreach and Reply Intelligence.

## Rationale

The immediate business goal is contract acquisition. The architecture must deliver value quickly while leaving a clean path to later SaaS/multi-tenant expansion.

## Consequences

Positive:
- fast personal value;
- reusable modules;
- future SaaS path;
- easier testing.

Negative:
- more upfront boundaries;
- some features remain deliberately incomplete in Phase 1.
