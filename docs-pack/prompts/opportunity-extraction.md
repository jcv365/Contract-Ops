# Opportunity Extraction

Extract:
- role;
- company/client;
- recruiter;
- start;
- duration;
- rate;
- currency;
- remote policy;
- location;
- technologies;
- seniority;
- clearance;
- work authorisation;
- language;
- next action;
- deadline.

Use null for missing values.
Never guess.
Return confidence per extracted field.
