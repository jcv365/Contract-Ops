# Reply Classification

Classify the incoming recruiter/client reply.

Allowed:
INTERESTED
OPPORTUNITY
REQUEST_CV
REQUEST_PROFILE
REQUEST_RATE
REQUEST_CALL
NOT_SUITABLE
FUTURE_OPPORTUNITY
OUT_OF_OFFICE
REJECTED
DO_NOT_CONTACT
UNKNOWN

Extract only values supported by the email.

If a new opportunity exists, return a structured proposed opportunity and source it to the email/thread.
