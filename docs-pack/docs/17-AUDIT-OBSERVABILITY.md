# Audit and Observability

## Every important action must be traceable

Record:
- source searches;
- source failures;
- opportunity discovery;
- deduplication decisions;
- eligibility decisions;
- scoring;
- recruiter verification;
- BIDOPS research;
- draft creation;
- edits;
- approval;
- send;
- Graph result;
- reply ingestion;
- classification;
- opportunity extraction;
- follow-up.

## Metrics

Track:
- source success rate;
- source freshness;
- opportunity yield;
- qualified yield;
- recruiter verification rate;
- outreach approval rate;
- send success rate;
- reply rate;
- positive reply rate;
- opportunities created from replies;
- contract pipeline value.

## AI traceability

Record:
- model/provider;
- prompt version;
- task;
- evidence IDs;
- confidence;
- validation result.
