# UI Requirements

Phase 1 UI should prioritise speed and decision making.

## Main dashboard

Show:
- new opportunities;
- high-fit opportunities;
- recruiter targets;
- company targets;
- pending approvals;
- follow-ups;
- replies;
- active pipeline;
- search coverage.

## Opportunity card

Show:
- title;
- company;
- recruiter;
- source;
- rate and ZAR;
- duration;
- remote status;
- eligibility;
- fit score;
- risks;
- direct URL;
- recommended action.

## Recruiter card

Show:
- company;
- recruiter;
- specialism;
- region;
- verified email;
- email type;
- last contact;
- response history;
- recruiter score;
- recommended proposition.

## Approval screen

Show:
- recipient;
- verification status;
- greeting;
- subject;
- body;
- evidence used;
- attachments;
- risks;
- previous contact;
- approve/edit/reject.

No hidden send action.
