# Phase 1 Project Overview

## Product

**HUNT Contract Acquisition OS — Phase 1**

A personal system designed to help one senior cloud architect find and win remote international contracts.

## Primary outcome

Increase the number and quality of viable routes to the user's next contract.

The system must not depend solely on advertised vacancies.

## Two acquisition engines

### A. Opportunity Hunt

Find:
- freelance contracts;
- consulting engagements;
- contract architecture roles;
- SOW/project opportunities;
- remote transformation work;
- relevant procurement/framework opportunities where practical.

### B. Market Outreach Hunt

Find:
- specialist recruiters;
- recruitment companies;
- professional services/consulting companies;
- cloud consultancies;
- systems integrators;
- potential subcontracting partners;
- direct client targets;
- appropriate decision makers.

The system determines whether to send:
- CV;
- company capability profile;
- both;
- or neither until more information is available.

## Core workflow

HUNT → Validate → Score → BIDOPS → Human Approval → Graph/Outlook → Reply Intelligence → HUNT/CRM update.

## Phase 1 exclusions

Do not implement:
- subscription billing;
- public marketplace;
- multi-tenant admin UI;
- recruiter marketplace;
- full ATS automation;
- autonomous email sending;
- broad legal advice;
- fully autonomous procurement bidding.

The architecture must not prevent these later.
