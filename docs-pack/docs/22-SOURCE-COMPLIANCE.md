# Source Compliance

Before enabling a source adapter, record:

- source name;
- official terms URL;
- API terms if applicable;
- licence if code is reused;
- permitted extraction method;
- rate limits;
- authentication requirements;
- attribution requirement;
- redistribution restrictions;
- privacy considerations;
- last reviewed date.

## Do not

- bypass CAPTCHA;
- bypass authentication;
- evade rate limits;
- defeat anti-bot controls;
- misrepresent identity;
- redistribute restricted feeds.

## Preferred source order

1. Official API
2. Official RSS/feed
3. Publicly documented endpoint permitted by terms
4. Public webpage access where permitted
5. Other methods only after explicit review

If uncertain, disable the adapter and document the issue.
