# BIDOPS Engine

## Purpose

Turn a validated target into a high-quality, evidence-backed proposition.

BIDOPS is not a generic email generator.

It must understand:
- target;
- target's market;
- target's likely need;
- opportunity;
- user's evidence;
- company capabilities;
- prior communication;
- commercial context.

## Outputs

- recruiter outreach;
- company introduction;
- opportunity proposal;
- follow-up;
- call preparation;
- negotiation response;
- CV/company-profile recommendation.

## Evidence rule

Every factual claim must reference evidence.

If evidence is missing:
- omit claim;
- or explicitly mark it as unknown.

## Personalisation

Use meaningful personalisation:
- market/specialism;
- current opportunity;
- company capability;
- relevant proof point.

Do not use superficial name insertion.

## Length

Default first-touch email target:
120–180 words.

Longer only when the opportunity demands it.

## CV/company profile decision

Recruiter for individual role:
- CV normally primary.

Consultancy/partner:
- company profile may be primary, CV secondary.

Direct client:
- choose based on engagement type.

Always show the proposed attachments before approval.
