# Remote Source Catalogue

Awesome Remote Job and similar public catalogues are discovery inputs, not proof that an opportunity is eligible.

Use them to discover:
- remote job boards;
- aggregators;
- remote-first company lists;
- communities;
- newsletters;
- regional sources.

For every discovered source:
1. register it;
2. independently verify its current availability;
3. record terms/licensing;
4. assess whether it is appropriate for HUNT;
5. build an adapter only when justified.

Do not scrape or redistribute data contrary to source terms.

Source catalogue inclusion never means:
- job is active;
- job is contract;
- job is remote from South Africa;
- user is eligible;
- source permits automated extraction.
