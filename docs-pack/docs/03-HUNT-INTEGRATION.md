# HUNT Engine

## Objective

Continuously discover and qualify contract opportunities worldwide.

## Search modes

### Live opportunity search
Search current/open listings and project adverts.

### Market discovery
Find recruiters, recruitment companies, professional services firms, cloud consultancies, systems integrators, partners and direct-client targets.

## Search strategy

Do not rely on one title.

Use:
- architecture titles;
- cloud platform terms;
- technical skill combinations;
- transformation terms;
- FinOps/cloud economics;
- AI/platform architecture;
- infrastructure/data-centre/network transformation;
- SOW/project/contract/freelance terminology.

## Opportunity freshness

Retain active, relevant, unapplied opportunities under 30 days old even if discovered previously.

Exclude expired/closed opportunities.

## Hard filters

Validate:
- remote;
- contract;
- seniority;
- architecture relevance;
- security clearance;
- work authorisation;
- mandatory language;
- location/onsite requirements;
- permanent status;
- engineer-only/developer-only nature.

## Scoring

Keep separate:
- technical fit;
- contract fit;
- remote fit;
- eligibility;
- commercial fit;
- recruiter accessibility;
- overall priority.

Hard-filter failures must not be represented as actionable high scores.

## Output

Every opportunity must contain:
- source;
- direct URL;
- advertised/discovered date;
- company;
- recruiter if available;
- location;
- remote policy;
- contract type;
- duration;
- rate;
- original currency;
- ZAR conversion;
- eligibility notes;
- fit score;
- reasons;
- gaps;
- status;
- provenance.
