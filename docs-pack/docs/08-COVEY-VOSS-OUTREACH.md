# Outreach Methodology — Covey + Chris Voss

## Principle

Use these frameworks as communication principles, not as manipulation.

### Covey
- seek first to understand;
- focus on the other party's needs;
- establish credibility through relevant evidence;
- create mutually beneficial next steps.

### Voss
- tactical empathy;
- calibrated questions;
- low-friction calls to action;
- avoid pressure;
- surface constraints;
- use "how" and "what" questions where appropriate;
- avoid premature rate anchoring;
- use an accusation audit when a genuine objection is likely.

## First-touch objective

The first email is not supposed to close the contract.

It should earn:
- a reply;
- a short conversation;
- permission to be considered;
- a request for CV/profile;
- or a relevant opportunity.

## No manipulation

Never use:
- fake scarcity;
- false urgency;
- fabricated competing offers;
- deceptive claims;
- fake familiarity.

## Calibrated CTA

Prefer low-friction questions such as:
- "Would it be unreasonable to explore whether..."
- "How are you currently handling..."
- "What would be the best way to determine whether my profile could fit..."

Use naturally; do not mechanically insert a phrase into every email.
