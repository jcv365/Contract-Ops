# Phase 1 Daily Operating Model

The app should support this daily workflow.

## 1. Run HUNT

Search all enabled worldwide sources.

## 2. Review opportunities

Prioritise:
- strong fit;
- fully remote;
- contract;
- eligible;
- good commercial value.

## 3. Review market targets

Prioritise:
- verified recruiter email;
- strong Azure/cloud relevance;
- contract/freelance placement evidence;
- international/remote evidence.

Then:
- professional companies;
- subcontracting partners;
- direct clients;
- procurement/framework targets.

## 4. Approve outreach

For each target:
- inspect recipient;
- inspect verification;
- inspect email;
- inspect evidence;
- inspect attachments;
- approve/edit/reject.

## 5. Send

Graph sends from user's mailbox.

## 6. Review replies

Classify and promote opportunities.

## 7. Follow up

Show due follow-ups. No automatic send without approval.

## 8. Learn

Track which:
- sources;
- recruiters;
- companies;
- messages;
- proof points;
- markets

produce results.
