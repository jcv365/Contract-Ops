# Phase 1 Acceptance Criteria

Phase 1 is successful when all of the following work.

## HUNT

- User can run a worldwide search.
- Search coverage is visible.
- Opportunities are deduplicated.
- Active remote contracts are identified.
- Hard filters are enforced.
- Fit scores are evidence-backed.
- Foreign rates are converted to ZAR.
- Direct application/source URLs are retained.
- Closed opportunities are excluded.

## Recruiter market hunt

- System can discover recruiters worldwide.
- System can discover professional/consulting companies.
- Relevant company/recruiter contacts are stored.
- Verified emails are distinguished from unverified emails.
- No email can be guessed and treated as verified.
- Recruiter/company targets can be prioritised.

## BIDOPS

- Research is target-specific.
- Claims are evidence-backed.
- CV vs company profile is recommended.
- Emails are concise by default.
- Covey/Voss principles are applied naturally.
- Personal greeting only occurs with verified named email.

## Outreach

- User sees exact recipient and verification status.
- User must approve before send.
- Graph sends approved email.
- Attachments work.
- Send is idempotent.
- Audit trail exists.

## Replies

- Replies can be ingested when enabled.
- Replies are classified.
- New opportunity information is extracted.
- Proposed opportunities retain email provenance.

## Reliability

- Tests pass.
- Secrets are not logged.
- Source failures are visible.
- No autonomous outbound communication exists.

## User outcome

The user can run HUNT, identify high-priority opportunities and market targets, approve personalised outreach, send it through Outlook, and see replies/opportunities flow back into the system.
