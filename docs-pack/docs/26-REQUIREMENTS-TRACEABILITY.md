# Requirements Traceability

Every requirement must map to implementation, automated test and acceptance criterion.

Maintain: `Requirement ID | Requirement | Implementation | Test | Acceptance Criterion | Status`

Critical requirements include worldwide coverage, remote/contract validation, hard filters, deduplication, ZAR conversion, provenance, source failure visibility, recruiter/company discovery, email verification, no guessed email, evidence-backed BIDOPS, CV/profile selection, human approval, Graph authentication, idempotent sending, audit trail, reply ingestion/classification/extraction, secret protection, least privilege, prompt-injection handling and PII controls.

No requirement is complete without a passing test.
